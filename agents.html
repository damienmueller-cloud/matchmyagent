Match preference

Branch first · Pro second · Verified third

When a seller’s suburb is known, MatchMyAgent prefers agents in this order:

  • Branch for the suburb cluster that includes that suburb (one Branch seat per cluster)
  • Pro for that exact suburb
  • Verified Profile agents eligible for the area

Paying buys the tools listed on each plan and the preference position above. It does not guarantee a lead. Application ≠ automatic subscription. Agencies may hold multiple Branch clusters at $749/mo GST-inclusive each.
